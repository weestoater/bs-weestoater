GIT WORKFLOW EXAMPLE
═════════════════════════════════════════════════════════════════════════════

1. Start Feature Branch
   $ git checkout -b feature/strava-setup
   $ git push -u origin feature/strava-setup

2. Work & Commit (small, focused commits)
   $ git add src/services/stravaService.ts
   $ git commit -m "feat(strava): implement OAuth token refresh"
   $ git push

3. Keep Updated (rebase if main advances)
   $ git fetch origin
   $ git rebase origin/main
   $ git push --force-with-lease

4. Create PR
   → GitHub: New Pull Request
   → Base: main, Compare: feature/strava-setup
   → Link to migration plan
   → Add checklist

5. After Review & Tests Pass
   $ git checkout main
   $ git pull origin main
   $ git merge --squash feature/strava-setup
   $ git commit -m "Merge feature/strava-setup"
   $ git push origin main

6. Cleanup
   $ git branch -d feature/strava-setup
   $ git push origin --delete feature/strava-setup
